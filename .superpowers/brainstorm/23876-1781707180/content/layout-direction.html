Donote layout direction

Select the visual direction that best matches your idea of a more modern, beautiful, and usable note app.

A. Modern writing workspace

Keep the three-pane note workflow, but make it calmer: compact command bar, clearer hierarchy, refined panels, polished tabs, and a paper-like editor.

B. Element Plus app shell

Adopt Element Plus patterns for header, aside, drawers, dialogs, buttons, tabs, and forms. More consistent controls, but a heavier UI dependency.

C. Focus-first editor

Make writing the dominant surface with side panels as drawers or rails. Beautiful and immersive, but file navigation and outline become less visible.
