Element Plus visual style

Pick the style direction for the full Element Plus migration. This decides spacing, panel treatment, color use, and the editor surface.

A. Clean productivity

Bright, structured, familiar desktop-app feel. Best if you want Element Plus to look crisp, predictable, and professional.

B. Calm writing tool

Light neutral panels with teal accents. More refined and less corporate, while staying practical for repeated note work.

C. Dark command center

Dark-first, high contrast, more technical. Strong for night use, but less aligned with a calm writing-first default.
